# ERRORS —— 软化翻车记录

> 状态：`open`（未验证）→ `resolved`（已验证可行）→ `stale`（已过时失效）

## 条目格式

```
ERR-YYYYMMDD-NN | 场景 | 坑 | 正确做法 | 状态
```
